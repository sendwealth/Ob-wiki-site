# Dribbble

## 概况
- 定位：全球顶尖设计师与创意专业人士的发现与雇佣平台
- 官方使命原文：*"We are where designers gain inspiration, feedback, community, and jobs."*
- 形态：从"作品展示站"演化为**设计服务双边市场**（连接客户与设计师）

## 战略方向（2025–2026）
官方在 2025-12《Work In Progress》明确战略重心：

> "Dribbble exists to help **service providers generate and convert leads**. The purpose of everything we do — every feature, policy, and campaign — is centered on that."

即一切功能/政策/活动都服务于"帮设计师获客并转化"。

## 双边市场结构

### 🎨 雇佣方（客户）端
- **Start Project Brief**：免费发布需求，获取设计师提案
- **Browse Profiles**：直接浏览联系设计师
- **Explore Services**：购买打包服务快速雇佣
- 促销：首单 8 折（最高减 $100），码 `WELCOME20`

### 💼 被雇佣方（设计师）端
- **Browse Project Briefs**：浏览需求主动投标
- **Add Service**：上架打包服务
- **Send Outbound Proposal**（新功能）：可向任何客户发提案
- 平台内安全收款

## 内容形式：Shots
- 核心单元叫 **Shot**（一张作品图/动图/视频）
- 顶部默认展示 **Popular**（热门）+ **New & Noteworthy**（新锐推荐）

### 8 大设计分类
Animation / Branding / Illustration / Mobile / Product Design / Print / Typography / Web Design

### 质量管控
每年发布 **Dribbble Select：Best Shots of the Year**，覆盖 branding/web/product/app 等领域，设平台质量标杆。2026 年度榜单已发布。

## 商业模式
| 收入来源 | 说明 |
|---|---|
| Pro 订阅 | 设计师付费会员，曝光权重更高 |
| 交易服务费 | Brief 提案 / 服务成交抽成 |
| 广告 | Framer 等在投广告位 |
| 全职招聘 | Post a Full-Time Job |

## 技术栈
- 前端：Vite + Vue.js、Shoelace Web Components、Flickity 轮播
- 字体：自研 WF Visual Sans + Mona Sans（Google 字体家族）
- 托管：Cloudflare（Bot 管理）、Stripe 支付
- 分析：GA4 + GTM

## 与同类平台对比
- **Behance**（Adobe）：偏完整项目集，集成 Adobe 生态
- **Dribbble**：偏单图（Shot）即视感，社区 + 接单导向更强

## 启示
> [!tip] 双边市场的战略聚焦值得借鉴
> Dribbble 把"帮服务方获客转化"作为一切功能的唯一北极星指标，这种**单一焦点战略**对 indie maker / 独立开发者选品有参考价值——平台的所有功能都为一个可量化的商业目标服务。
