# 用户痛点发现方法论

## 五条路径
1. **自身痛点** — 你最近烦什么？愿意花钱解决什么？
2. **身边人痛点** — 朋友/同事/家人抱怨什么？
3. **搜索引擎** — "alternative to X" 长尾词
4. **社区论坛** — Reddit/V2EX/知乎的吐槽帖
5. **差评挖掘** — App Store/G2/Capterra 的1-3星差评

## 验证清单
| 维度 | 问题 |
|------|------|
| 频率 | 每天 > 每周 > 每月 |
| 痛苦程度 | "不做不行" > "有点烦" |
| 付费意愿 | 现有方案是否收费？ |
| 用户群体 | 多少人？在增长吗？ |
| 替代方案 | 现在怎么解决？Excel？忍受？ |

## 2026 机会方向
- AI 落地的最后一公里
- 本地 AI + 隐私
- 垂直行业 AI 改造
- 信息过载 → 过滤/总结/决策
- 老龄化相关服务
