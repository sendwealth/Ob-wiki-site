# AI Agent 生态概览

> [[ai-workflow-landscape|← AI Workflow 开源项目全景]]

AI Agent 生态正从“单模型调用”演进为“多 Agent 协作 + 工具市场 + 协议层”的体系。主要组成部分包括：

- **Agent 框架**：LangChain、LangGraph、CrewAI、AutoGen、Agno、ADK、OpenAI Agents SDK
- **编排平台**：Multica、Flowise、n8n、Dify、Deer-Flow
- **工具协议**：MCP（Model Context Protocol）、A2A（Agent-to-Agent）
- **能力层**：Browser-Use（浏览器自动化）、Firecrawl（Web 数据）、OpenHuman（数字人）、Orloj（K8s 原生 Agent）
- **基础设施**：OpenShell / Kagent（安全沙箱）、Temporal / Polos（持久执行）
