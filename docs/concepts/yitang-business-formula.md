# 业务公式拆解方法（一堂·孔源）

> 来源：[专家分享｜如何用业务公式，驱动业务不断提升？（孔源）](../raw/yitang/业务公式驱动业务提升-孔源-原文整理.md)
> 标签：#方法论 #业务拆解 #一堂 #创业

## 一句话

业务公式的价值不在于写出漂亮公式，而在于拆完后知道先做什么、怎么做、怎么验证。

## 业务公式有用的三个条件

| 条件 | 含义 |
|------|------|
| **看得清** | 业务的根本矛盾到底在什么问题上 |
| **想得透** | 在这个矛盾下，到底有哪些要素？优先级是什么 |
| **做得准** | 面对要素能提出哪些假设？有没有清晰的数据判断依据 |

## 四个认知突破

### 1. 只记大公式，不进行细分 → 有盲区

只拆一组公式，一定有盲区。核心技巧：**先判断业务类型**。

- **单次成交型**（房产、汽车、装修）：核心瓶颈在"怎么从触达到成交"。关注收入提升类公式。
- **持续复购型**（SaaS、私域电商、会员）：不光要"卖出去"，更要"留得住"。关注竞争提升类公式和留存公式。

典型误区：10W人社群GMV只有100万/月，问题不是"人不够多"而是"每个人都没怎么买"（单客价值问题）。

### 2. 随意提参数，不考虑数字 → 太浅

**参数冰山 L1-L6：**
- L1-L2：只是"业务科目"，不是"业务抓手"。停在L2只能说"转化率太低要优化"——正确但无用的废话
- L3-L4：能指导团队干活。定性参数必须拆成**可定量的行为指标**（每个定性参数找3-5个行为指标）
- L5-L6：本质洞察、战略级认知。L6示例：客户成功本质 = 决策者认可 × 推动者有抓手 × 使用者离不开了

### 3. 逻辑不清晰，优先级混乱 → 会误导决策

**相关关系只能看趋势，因果关系才能做决策。**

三个核心技巧：

**① 先切分（+），再拆转化（×）**
- 第一步：GMV = 新用户GMV + 复购用户GMV + 转介绍GMV
- 第二步：新用户GMV = 曝光量 × 点击率 × 落地页完成率 × 支付转化率 × 首单客单价
- 不切分直接拆"总公式"，拆出来的参数关系对谁都不准

**② 判断运算符号**
- **+（叠加）**：多一个更好，缺一个不影响整体。如：信任度 = 信任背书1 + 信任背书2 + 信任背书3。有一个就够了。
- **×（漏斗）**：缺一不可，一个环节断了整个链条就断了。如：转化率 = 触达率 × 打开率 × 点击率 × 下单率
- 把"+"写成"×" → 平均用力找不到重点；把"×"写成"+" → 关键环节被忽略

**③ 从相关到因果**
- 相关：A和B一起变化，但A不一定导致B（投放增加、转化率下降，真正原因是流量质量下降）
- 因果：A变化→B一定变化，控制其他变量后A仍是B的原因
- 示例：满意度→到店频率→到店习惯→续卡率。满意度是"因的因"，不是"直接原因"

### 4. 随意做假设，没数据埋点 → 不可验证

每一个定性参数、每一组参数关系，都必须找到可定量的行为指标来佐证。没有数据埋点的假设永远是假设。

## 实用框架

### 定性→定量拆解模板

| 定性参数 | 可定量行为指标 | 健康值 |
|---------|--------------|--------|
| 信任度 | 详情页下滑完成率 | >80% |
| 信任度 | 试听课完课率 | >70% |
| 信任度 | 咨询会话发起率 | >15% |
| 满意度 | 扫码评价提交率 | >40% |
| 复购触发 | 7天内优惠券核销率 | >20% |
| 场景绑定 | 工作日午餐消费占比 | >60% |

### 拆解深度判断标准

一个参数能不能提出**可验证的假设**？如果能，拆到这个深度就够了。如果不能，继续往下拆。

## 关键金句

- "L1-L2的参数只是'科目'不是'抓手'"
- "相关关系只能帮你看趋势，因果关系才能帮你做决策"
- "拆完之后，你知不知道该先做什么、怎么做、怎么验证"
- "能拆到L5-L6，是顶级业务负责人和普通执行者的分水岭"
- "不切分直接拆总公式，拆出来的参数关系对谁都不准"
