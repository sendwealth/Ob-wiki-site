# MAKE: The Indie Maker Blueprint

> 作者：Pieter Levels (@levelsio) | 网站：https://readmake.com/
> 一本关于以独立开发者方式构建盈利创业公司的实战手册。

## 作者背景

Pieter Levels 是自学编程的荷兰开发者，一个人构建了 Nomads.com、Remote OK、PhotoAI 等多个成功产品。年收入超 300 万美元，曾两次获 Product Hunt 年度 Maker。Lex Fridman、John Collison 等人均公开推荐。

## 核心理念

反对硅谷 VC 融资模式，主张 bootstrapping（自力更生）：
- 用自己的资源启动，目标不必是十亿美元公司
- 先做出能养活自己的产品
- Bootstrapping 不排除未来做大后再融资——VC 更喜欢已有收入的公司

## 七步框架

### 1. IDEA（想法）
- 从自己的问题出发，不要"找解决方案再找问题"
- 让自己变得更有趣，想法自然更有趣
- 从微小利基市场开始 → 多个利基 → 相邻市场 → 平台化
- 不要怕分享想法，执行力才是关键

### 2. BUILD（构建）
- 用你已经会的工具快速构建，别花一年学新语言
- 自己动手，外包是竞争劣势
- 只构建核心功能（MVP），其余以后再说
- 偏好约束：无融资、无团队、无完美设计 → 反而逼出创意

### 3. LAUNCH（发布）
- 尽早发布、多次发布
- 在 Product Hunt、Hacker News、Reddit 等平台发布
- 更重要的是找到你的目标用户聚集的地方，在那里友好地发布
- 语气："这是我做的一个可能对你有用的东西"，而非"我要颠覆世界"

### 4. GROW（增长）
- 有机增长 > 广告，好产品自带吸引力
- 通过 SEO、社交媒体、口碑、开放 API 等方式增长
- 不急着招人，保持精益

### 5. MONETIZE（变现）
- 直接向用户收费，不要卖数据、不要铺广告
- 不要害怕收费，收费本身就是验证
- 多种商业模式：订阅、一次性付费、市场佣金等

### 6. AUTOMATE（自动化）
- 用程序自动化重复工作，用 AI 替代人工流程
- 不值得自动化的就用外包 contractors
- 目标：一个人也能运营。作者预言将出现首个由单个创始人 + AI 机器人运营的十亿美元公司

### 7. EXIT（退出）
- 不要主动卖公司，让买家来找你
- 过滤掉不认真的买家，筛选严肃买家后谈判
- 报价要大胆偏高，保持谈判筹码
- 拿现金不要股票，当心 earnout 陷阱

## 关键金句

- 你可能需要做 10-30 个产品、坚持 1-3 年才能有一个成功
- "讨论用什么编程语言最好的人不是在发货产品的人"
- 做一个有道德的公司：不 spam、不操纵用户、不作弊。做个好人的道德优势本身就是竞争力
- 大量产品会失败，失败是正常的。不断尝试
- "Always keep shipping."

## 与当前方向的关联

> [!summary] 参考价值
> 这本书的方法论与"一人公司 + AI 多智能体协作"方向高度契合。Levels 证明了一个人可以做年收入百万美元以上的生意。关键不是宏大计划，而是：快速构建 → 快速发布 → 迭代 → 再做下一个。
