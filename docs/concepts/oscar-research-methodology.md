## 一、课程背景：为什么要学调研

### 1.1 调研是最被低估的核心能力

Truman 每月需要解决几十个大大小小的问题，他的核心习惯是：**所有高价值问题，不要着急拍脑袋，先从调研开始。**

加上 AI 辅助学习后，每周十几轮二十轮地让 AI 写调研报告，调研已经成为他使用最高频的 AI 工作场景。

### 1.2 调研的普遍困境

大家往往缺少一套专业的调研工作框架。常见的惨状：
- 把调研交给下属，容易忽略目标、跑偏
- 收集了大量无效冗余信息
- 忙活了很久、甚至花钱上课，最后发现调研价值微乎其微

**本质原因**：缺少一套科学高效的调研训练。

### 1.3 2026年新范式

Truman 预判学习和决策方式正发生重大变革：

| 原有范式          | 新范式                  |
| ------------- | -------------------- |
| 100%人学人用人解决问题 | 人类提供**审美、体系、创造力**    |
| 一切教育以人为主      | AI 承担**分析/判断/调研/执行** |

## 二、OSCAR 调研模型·总览

### 2.1 五个关键执行环节

```
O → 明确目标 (Objective)       心法：盯紧目标
S → 缩小范围 (Scope)           心法：足以支撑

A → 获取情报 (Acquisition)     心法：穷尽手段
R → 完成判断 (Reasoning)       心法：实事求是
```

## 三、Phase O：明确目标（4式）

> **心法：盯紧目标。** 没有目标，就不要谈效率。

### 3.1 常见的 O 阶段问题

| 错误类型 | 表现 | 后果 |
|---------|------|------|
| 没有分析目标 | 老板让我调研XX获客，我拿了全面信息，结果老板只是想判断投放可行性 | 跑偏 |
| 忘掉初心 | 反正有时间，尽量多搜集信息呗，最后信息一大堆忘了目标 | 无法决策 |

### 3.2 好的调研目标 vs 坏的调研目标

**坏的**：「了解同行」「看看同行最新动作」——太粗糙，手段不是目标。

**好的**：「研究同行新品的销量和利润，决策是否跟进」——落到最终决策。

**核心原则**：调研的本质是为了**回答问题，指导关键决策**。多问几个为什么，落到最终决策来思考。

### 3.3 四大决策类型

| 类型 | 定义 | 典型问题 |
|------|------|---------|
| **选择题** | 从N个选项中选最优 | 「东南亚/中东/拉美，先做哪个？」 |
| **解答题** | 验证一个假设是否成立 | 「获客成本到底多少？项目能否赚钱？」 |
| **设计题** | 参考最佳实践来设计 | 「分销系统怎么设计？定价怎么定？」 |
| **竞争题** | 监控竞对动态 | 「竞品在哪些城市领先？订单量多少？」 |

#### 选择题范例
- 家庭教育知识付费——线上课程、年度会员、训练营，哪种盈利模式？
- 银发经济——适老化改造、老年租赁、老年门店，哪个天花板高？
- 美妆新品——实验室成分、国潮设计、医用级，哪个更有机会？
- 奶茶加盟——喜茶、一点点、茶百道、蜜雪冰城，哪家？
- AI玩具渠道——小红书、视频号、抖音、快手、淘宝，怎么选？

#### 解答题范例
- 电流测量仪——国外同行卖得好不好？赚不赚钱？
- 美容院店中店——引入中医科是否可行？
- SaaS续费率下滑——背后原因是什么？
- 写字楼打印店——每月能赚多少？
- 风水培训课——是否有人愿意付费？

#### 设计题范例
- 乡村民宿——设计有地方特色又能标准化交付的接待方案
- 宠物上门喂养——设计服务流程缓解「陌生人进屋」顾虑
- 情绪疏导小程序——设计友好有扩展性的界面
- 老人AI产品——设计新手引导流程
- 创业者短视频——解决批量爆款内容的格式一致性

### 3.4 调研频率经验

「如果你在管团队或业务，每周没有1-5轮调研任务，大概率不够。」解决各种新问题时，「调研先行」的渗透率基本在 50-70%。

### 第1式：调研先行（选择题）

**核心**：别着急做选择，先调研。

**案例**：
- 张磊：扭蛋机、酸奶、养老院、锦鲤电商——通过调研验证跑出了洗发水业务
- Truman：五六个赛道、几十个机会里一步步收集信息预判，选择了线上创业轻培训

### 第2式：验证假设（解答题）

**核心**：做了选择后，低成本验证可行性。

三种验证方式：
1. **靠常识**——找行业专家直接聊
2. **靠调研**——搜集市场竞争情报信息做判断 ✔️
3. **靠验证**——自己设计实验验证商业模式

**血泪案例**：秦鹏研发「专业电流测量仪」——花了一年时间、投入50万研发成本，预期每年卖20万台，最后连3000台都很费劲。反思：提前调研同行销量+拜访客户，答案不难拿到。

**关键提醒**：假设是分层的，越具体调研价值越高。例如「AI老年大学」：
```
第一层：我能做AI老年大学吗？
第二层：国内有跑出来的商业模式吗？
第三层：产品内核是什么？
→ 越小的层级，调研质量和速度越好
```

### 第3式：最佳实践（设计题）

**核心观点**：「你的执行力的上限，不会超过你对最佳实践理解的下限。」

就像马拉松前面有人领跑破风，你跟跑会省力很多。一旦见识过真正先进的东西，无需探索试错。

**以太原则**：不发明轮子，抄最好的轮子。产品内核独特，但形式全部来自最佳实践。

### 第4式：竞对跟踪（胜出题）

排在 O 阶段最后一位——增长和竞争是商业模式验证之后的工作。

**适用条件**：
- 分散、竞争弱的市场 → 可忽略
- 你死我活、竞争激烈的市场 → 必须认真关注

**案例**：某大厂，每个城市每月订单量/市占率/排名一目了然，用作战地图驱动策略。

## 四、Phase S：缩小范围（3式）

> **心法：足以支撑。** 最好的支撑是科学的因果规律。

### 核心认知

> 「你的调研能力，就是你的业务能力。」不要盲目套模板——每个调研的目标、模型、范围都不一样。

### 第5式：内核边界（三层剥离）

```
边界外：果断放弃（再香也不要）
  中间：接受模糊（可做可妥协）
    内核：最关键、必要、决定性的
```

### 第6式：宏中微观·七层模型

| 层 | 关注点 | 适用场景 |
|----|--------|---------|
| 1 SOP | 执行细节 | 落地复制 |
| 2 ROI | 转化节点 | 增长优化 |
| 3 业务公式 | 业务逻辑 | 中期规划 |
| 4 单元模型 | 最小经济闭环 | **验证能否赚钱**（核心） |
| 5 商业模式 | 259五步法 | 商业模式验证 |
| 6 完整公司 | 业务+组织 | 公司战略 |
| 7 行业 | 趋势格局 | 大方向选择 |

> 关键建议：拆成微观要素调研，而非找一模一样的案例

### 第7式：科学模型·16个因果规律

| 模型 | 场景 | 核心价值 |
|------|------|---------|
| **机会预判** | 方向选择 | 主动想终局、充分做加法、专业做减法 |
| **一堂五步法** | 商业拆解 | 需求→方案→模式→增长→壁垒 |
| **需求原点** | 需求分析 | 目标用户+场景+问题，拆推评算 |
| **JTBD** | 需求剥离 | 用户「雇佣」产品完成待办任务 |
| **产品内核** | 产品设计 | 用户愿意选择你的最小解决方案 |
| **单元模型** | 盈利验证 | 最小经济闭环，复制哪个算哪个 |
| **规模经济** | 规模分析 | 规模变大，哪些变好哪些变差 |
| **网络效应** | 用户增长 | 用户增多后的价值变化 |
| **壁垒模型** | 竞争优势 | 护城河分析 |
| **增长飞轮** | 增长驱动 | 增长循环设计 |
| 定价/组织/竞对/财务/融资/退出 | 专项 | 各领域分析工具 |

做题测试：
- 网站办卡率为什么高？ → 动力阻力触点模型
- 公司知识管理怎么做的？ → IPO模型
- 工业化短剧为什么牛？ → 工业化生产模型
- IT外包为什么能做很大？ → 规模对抗模型

## 五、Phase C：罗列清单（5式）

> **心法：头脑清晰。** 任何一个产品都不是孤立的。

### 第8式：设定标签

加限定词做减法。示例：
- 调研快餐 → 正餐品类，2公里内，人均40-60元
- 调研SaaS → 行业头部，线下获客，二三线城市
- 调研零食 → Z世代，助眠功效，15-30元，小红书种草

### 第9式：竞争象限 ⭐

按【需求 × 模式】两个维度，划分三类：

| 象限 | 定义 | 调研目的 | 数量 |
|------|------|---------|------|
| **直接竞品** | 同需求 + 同模式 | 竞争对标 | 3-8 |
| **间接竞品** | 同需求 + 不同模式 | 用户痛点分析 | 5-15 |
| **可借鉴产品** | 不同需求 + 同模式 | 最佳实践学习 | 5-20 |

**BP应用**：
- 间接竞品 → 「用户痛点」→ Why Now？「现有方案ABC都不够好，所以我有机会做D」
- 直接竞品 → 「竞争分析」→ Why Me？「因为123核心能力，我们有能力胜出」

**关键认知**：横向（竞争）希望对手少，右侧纵向（同模式）希望可借鉴多。

### 第10-12式

- **二维定位**：在象限图上标出各家位置
- **按图索骥**：排定调研优先级
- **数量预期**：设定上限，避免调研过载

## 六、Phase A：获取情报（2式）

> **心法：穷尽手段。**

### 第13式：调研武器库

| 情报类型 | 工具/渠道 |
|---------|----------|
| 公开数据 | 财报、招股书、行业报告、艾瑞/易观、Statista |
| 用户声音 | App Store评论、社交媒体、Reddit/V2EX/知乎、客服 |
| 竞品产品 | 官网、产品体验、定价页、帮助文档 |
| 一手情报 | 专家访谈、用户访谈、行业会议、问卷 |
| 技术情报 | GitHub、专利检索、技术博客 |
| AI辅助 | AI信息搜集+交叉验证 |

### 第14式：穷尽手段

- 至少用 **3种不同渠道** 交叉验证
- 关键信息必须 **至少2个独立来源**

### 专家访谈技巧

三个追问：
1. 为什么？
2. 底层逻辑是什么？
3. 反例怎么看？

**错误示范**：专家说「低频业务没法支撑O2O」→ 创业者说「哦好」
**正确示范**：追问「为什么？」→「那闪送为什么行？」→「新氧为什么行？」→ 挖到本质

> 「真正的高手，可以挖掘事物背后的原因和推导过程。」

## 七、Phase R：完成判断（4式）

> **心法：实事求是。**

### 第15式：事实优先

| 标记 | 类型 | 定义 |
|------|------|------|
| ✅ | 事实 | 有证据链、可验证 |
| 💬 | 观点 | 专家/用户主观看法 |
| ❓ | 推测 | 逻辑推导但未证实 |

### 第16式：定量建模

关键问题：市场多大？增速多少？获客成本？LTV？回本周期？ROI？

### 第17式：交叉验证

- 同一信息 ≥2个独立来源？
- 数据一致吗？不一致 → 为什么？哪个更可信？

### 第18式：深度归因·三层法

```
表象：「竞品A最近涨得很快」
  ↓ 为什么？
直接原因：「投了抖音信息流，ROI 1:3」
  ↓ 为什么？
底层原因：「产品内核是内容+社区，天然适合短视频；
           我们是纯工具型，同样投放ROI只有1:0.8」
```

## 八、AI 调研新范式

### 核心逻辑

> 人提供 OSCAR框架 + 上下文 + 审美判断
> AI 承担 信息搜集 + 整理 + 交叉验证

### 真实案例

| 案例 | 传统方式 | AI方式 | 结果 |
|------|---------|--------|------|
| 公司背书PPT调研 | 派员工 2-4周 | 30分钟 + 25轮交互 | 应愿意付费质量的报告 |
| 家具出海选国家 | — | 张磊 + AI Partner | 完整国家对比报告 |
| AI时间管理工具 | — | 早期idea验证 | 完整市场预判 |

### 关键教训

**不能让AI一杆子做完。** 全程只喊「继续」→ 不可靠。交互式才有效：人用专业框架纠偏，AI高效执行。

### 使用前提

想深度使用AI Partner，需要：笃定的业务理解 + 专业的调研方法论 + 熟练的OSCAR模型。
