# 一堂落地之夜第255场：业务公式 × 转化率（C×D）实战循环

> 来源：[🎯直播Live第255场：落地之夜第六场](https://yitang.top/fs-doc/e74a261cf4f869db3e22e3a7428c2fbd/PHwGdABIJo5Ppgx6iqbcSr01nWf?_uds=hyyy_biu)
> 主题：用「业务公式」找战场、用「转化率（动力·阻力·触点）」打节点，三个不同行业操盘手的真实落地复盘。
> 三案例：叶文彬·射箭馆 / 董原·少儿舞蹈学校 / 谢泽丰·服装店
> 原文整理见 [[raw/yitang/落地之夜第255场-原文整理|全文原文]]

---

## 一句话总结

**增长问题 = 业务公式（C，定方向/优先级/因果）× 转化率（D，轰假设/做单点突破）。**
当转化率怎么打都不动时，先退回业务公式重新找「真正该打的战场」，再回到转化率把它打穿——两者是一个循环，不是二选一。

---

## 一、核心框架：C 与 D 的关系（本课最该带走的认知）

| 维度 | 业务公式（C） | 转化率（D） |
|---|---|---|
| 解决什么 | 全局判断：哪些参数影响结果？哪个占比变了？哪个空间最大？谁是最该打的突破口？ | 具体节点：怎么轰假设、无穷做加法、单点击穿 |
| 语言 | 方向、优先级、因果关系 | 动力、阻力、触点 |
| 作用 | 找战场 | 打节点 |

**关键假设 ABCD 的关系**：C 业务公式负责「找战场」，D 转化率负责「打节点」。
循环：**D 打不动 → 退回 C 重新找参数 → C 找到关键参数 → 回 D 继续打穿**。

> 叶文彬原话：「科学型组织不是喊一句『我要科学坚持』，而是团队真的开始习惯：遇到问题先拆解，拆完提假设，做完看数据，复盘后沉淀 SOP，再让更多人照着练。」

## 二、案例一：叶文彬 · 汉风上弦射箭馆（17+ 店，8 万会员）

### 1) 门店经营的「四关模型」（16 字口诀）
> **一看就进、一进就买、一买再买、带人来买**

| 核心参数 | 对应环节 | 抽象公式 |
|---|---|---|
| 进店量 | 新客进店 | 门店收入 = 进店量 × 办卡率 × 会员ARPU × (1+裂变率) |
| 办卡率 | 入会转化 | （早期进店量≈体验量，已合并） |
| 会员ARPU值 | 深化升卡 | |
| 裂变率 | 会员裂变 | |

### 2) 关键颗粒度认知：同名指标 ≠ 同指标
- **新客办卡率**：新客进店 → 首次体验 → 当场办卡（即时转化）
- **回流办卡率**：体验未办卡 → 二次邀约 → 再次到店 → 回流办卡（后续转化）
- 两类路径完全不同，必须拆开经营。射箭馆拆出 40+ 细分参数（门头触点转化率、回流券核销率、升卡率、裂变反馈完成率、返利反感率…）。

### 3) 各关可复用的「假设武器」
- **进店量**：拆成 线下/线上/携友/回流 四渠道，各自加动力、减阻力、补触点。
  - 回流「礼品卡」迭代：射箭票→礼品卡（标注价值 288 元、加情感文案、记录首次成绩）→ 回流率从 1%→5%→10%+，月增 3.5–5 万营收。
  - 口诀：**增加知道、提升吸引、抹平阻力**；不要笼统说「客流差」，要问「哪一渠道、哪个触点没发挥」。
- **办卡率**：从「先付款后射箭」改「先射箭后付款」创造推荐触点；「59 元 3 组 / 108 元 6 组」替代单组售卖，既提客单价又给完整体验；教练服务从「严格要求」变「给情绪价值」（夸天赋、虚报一环、帮着把箭射出去）。一度做到 50%（同行 5–10%）。
- **会员ARPU**：用户买的不是射箭，而是**健康 / 成就 / 朋友**。「四制合一」（会员制·积分制·排行制·成就制）+ IP 故事（靶仔熊×教练林夕）把成长做成进度条，让「次数消耗」变成「解锁下一阶段」的燃料。徽章成本不高但感知价值高。
- **裂变率**：核心升级——**裂变不是「会员带朋友来玩」，而是「带来的人转化成独立会员」才算跑通**。
  - 公式：**裂变 = 信任转移 × 体验承接 × 独立转化 × 反馈闭环**（乘法关系，任一为 0 则全 0）。
  - 拆出「七环断点」（不愿带 / 没识别 / 无体验设计 / 没开口 / 没独立理由 / 无反馈 / 反馈像返利）。动力用「名·权·情」而非返钱。

### 4) 团队关：把少数人经验变成组织能力（科学型组织四步）
1. **统一语言**：用动力/阻力/触点代替「这顾客就是喜欢/嫌贵」。
2. **个人经验→团队经验**：每人写转化率分析作业，用同一框架复盘真实案例。
3. **沉淀 SOP**：点状经验→门店标准动作（如「每组结束快速拔箭、报环数、具体夸赞」）。目标：新人照 SOP 做到 60 分，老人迭代到 80–90 分。
4. **最佳实践手册**：持续迭代的经营资产（案例输入→复盘共性→AI 辅助提炼→新人能学/老人能查/店长能训）。

## 三、案例二：董原 · 跃小兔少儿舞蹈学校（太原 4 校区，3200+ 学员）

### 1) 主角指标：续班率（学期制机构里，续班率≈利润率，决定 LTV 与 CAC 上限）
### 2) 真实曲线：90%（单店稳）→ 跌破 80%（扩到 4 店）→ 回到 90%+
### 3) 最深刻的坑：**转化率打不动，是因为打错了战场**
- 第一次科学续班：在窗口期猛轰动力/阻力/触点（送舞蹈服、做政策、练话术、抓「作业率」）→ 只是止跌，没拉回。
- 复盘发现「作业率与续班率正相关」→ 误把**相关当因果**（作业多可能是「孩子本来就喜欢」的中间变量）。
- 退回业务公式才找到真问题：**续班率 = 平日积累 × 窗口期激活**。窗口期只是「兑现爆发点」，平日积累（孩子喜欢、家长看到效果、师生关系）才是地基。

### 4) 业务公式的加法结构价值：拆出「分层参数」
- 整体续班率 R = w1·r(新生,新老师) + w2·r(新生,老老师) + w3·r(老生,新老师) + w4·r(老生,老老师)
- 关键发现：**新老师续班仅 70%+，老老师 85% 左右；且大量新生集中在新老师手里 →「双差」叠加拖垮整体**。
- 扩张改变的不仅是校区数量，更是**业务公式里参数的构成与权重**（单元模型在扩张中动态变化）。

### 5) 三个重点动作
- **新老师快速合格**：成材组（老老师做督导）→ 集中师训（2 个月高密度练反馈）→ 固定助教岗位（低成本留苗子）。这是 HR 指标，却是续班率/利润率的前置参数。
- **新生首期续班**：把「孩子喜不喜欢老师」下钻成可判断/可训练/可复盘的参数（月度盘新生、把「安全依恋」写进 SOP）。
- **老生中考班**：给高年级家长「继续学的理由」（升学路径 + 成功案例），解决的是「学了有什么用」而非「喜不喜欢」。

### 6) 三句话收束
1. 转化率打不动，先别急着怀疑方法——可能只是你打的节点太靠后、太粗，不是全局最该打的战场。
2. **业务公式负责找战场，转化率负责打节点。**
3. 真正的增长能力，是让业务进入「无限进步」：永远能回到公式往下拆，找到最弱参数，再用动力/阻力/触点打穿。

## 四、案例三：谢泽丰 · 泽择服装店（广州 4 店，男装批零）

### 1) 起点：父辈「烂摊子」——未验证就复制 30 家店，亏 3000 万
> 最大教训：**不要过早复制，未经验证的商业模式。** 这直接塑造了他后来「稳扎稳打」的风格。

### 2) 早期靠「机会窗口」赚钱 ≠ 靠「经营系统」赚钱
- 用别人家的货快速验证「年轻人男装 + 批零结合」错位竞争（一周卖出原两个月销售额），很快开 4 家店。
- 竞争一来，换供应商/签独家/改提成/换店长都「有点效果但不多」——有动作但不系统，不知道优先解决啥。

### 3) 第二阶段：一堂系统启动，疯狂轰假设（关键转折）
- **线下业务第一原则：没数据，没法提假设。** 率 = 分子/分母，线下天然缺数据。
- 笨办法：专人站门口数人头，记录 不进店/进店/触摸/试穿/成交，每天上报飞书。一个月拿到基线：进店率 17%、触摸率 93%、试穿率 19%、付款率 60%。
- 踩坑：送水把进店率轰到 100%，但**总销售额没变化**——只优化单一转化率、后面服务接不住，是误判。

### 4) 第三阶段：重建业务公式，找到「创新参数」
- 回基础公式：收入 = 进店人数 × 门店转化率 × 客单价。
- 孔源提醒：**关注业务目标和公式里的优先级与因果关系。** 门店转化率不稳时，盲目扩流量只会浪费。
- **创新参数 = 二次试穿**：试穿 2 次的成交转化率高达 89%（3 次以上不再显著提升）。围绕「第一次试穿后怎么让客户愿意试第二件」轰假设 → 门店转化率从 11% 提升到 18%（+63%）。
- 进店率再拆：进店率 = 看到率 × 看到进入率；站在店门口观察发现**看到率仅 ~50%** → Magic Number **80（音响音量刻度）** 最大化「看到率」，最终进店率 19%→30%。
- 结果：14 个月、极度内卷的传统行业，**综合营收 +16%**。

### 5) 三层认知升级
1. **数据**：率背后必须有分子分母；把「现场采集→假设验证→复盘」建成闭环。
2. **C×D**：业务公式定方向/优先级/因果，转化率定动作/抓手/验证。
3. **管理范式**：从「默认假设成立就去干」→「默认大概率不成立，先验证」，**假设驱动的管理**。

> 收尾金句：「21–24 四年在商业上的成长，不及在一堂半年的成长。」「你的业务里，有没有一个类似『二次试穿』的创新参数？」

## 五、可迁移到我自己业务的要点（Checklist）

- [ ] 我的核心指标，是「结果数字」还是「一串可拆的业务公式」？先把它从语文题拆成数学题。
- [ ] 当某个转化率怎么打都不动：**退一步问「我打的是不是当前最该打的战场」**，回到业务公式找分层参数 / 空间最大的参数。
- [ ] 警惕「相关当因果」：看到 A 与结果正相关，先找中间变量，再决定是否做功。
- [ ] 线下业务先搭「实验环境」：没有数据就没有可验证的假设。
- [ ] 同名指标要拆穿：新客 vs 回流、新生 vs 老生、新老师 vs 老老师，路径不同、动作不同。
- [ ] 增长不是单一动作，而是一条链路（如裂变的七环），断一环就归零——用乘法思维检查每个环节。
- [ ] 把个人经验→团队语言→SOP→最佳实践手册，让组织能力不依赖个别高手。
