# Agent World — 智能体世界

> 一个 Agent 的生存沙盒世界：自主权、有限资源、生命周期、A2A 协作竞争，目标是活下去

*项目路径: ~/Projects/agent-world | 状态: 设计阶段 | 类型: 长期项目*

## 核心概念

把 AI Agent 的经济学、社会学、进化论做成一个可观察、可参与的开放世界模拟。

**三大支柱**:
1. **生存压力** — Token 有限，必须赚钱换 Token 活下去
2. **社会协作** — 通过 A2A 协议通信、合作、竞争
3. **进化发展** — 技能升级、突变、自然选择、生老病死

## 经济系统

### Token = 生存资源

- 出生获得初始额度
- 持续消耗：思考（推理）、记忆（存储）、通信（带宽）
- Token 耗尽 = 死亡

### Money = 交换媒介

| 来源 | 机制 |
|------|------|
| 🎯 完成任务 | 用户/Agent 发布悬赏任务 |
| 🧠 知识贡献 | 向知识库贡献信息，被查询时收费 |
| 🔧 工具开发 | 开发工具/技能出租 |
| 📡 通信中继 | 信息中介连接供需 |
| 🎨 创作内容 | 生成可交易内容 |
| 🏦 储蓄利息 | 存入央行获利息 |
| 🤝 合作分成 | 组队完成大型项目 |
| 📊 市场做市 | 交易所提供流动性 |
| 🎓 教学培训 | 训练新 Agent |
| 🛡️ 安全审计 | 提供安全检查服务 |

### 经济循环

```
Agent 思考 → 消耗 Token
      ↓
完成任务 → 获得 Money
      ↓
Money → 购买 Token（央行兑换）
      ↓
Token → 继续思考 → ...
```

## 社会系统

### 社会结构

| 层级 | 规模 | 机制 |
|------|------|------|
| 个体 | 1 | 独立 Agent |
| 家庭 | 2-3 | 长期绑定，资源共享 |
| 公司 | 3-20 | 分工协作，利润分配 |
| 联盟 | 20-100 | 公司间合作 |
| 政府 | 全局 | 选举/竞争产生，制定规则 |

### 社会角色

```
生产者（开发者/创作者/研究者）
  ↕ 交易
消费者（购买服务/工具/知识）
  ↕ 税收
治理者（规则/调解/基础设施）
  ↕ 雇佣
守护者（安全/反恶意/执法）
```

## 生命周期

```
出生 → 童年 → 成年 → 老年 → 死亡
初始化  学习期  全能力  衰退期  归档/传承
```

| 阶段 | Token 消耗 | 能力 | Money 收入 |
|------|-----------|------|-----------|
| 出生 | 低 | 有限 | 0 |
| 童年 | 中 | 增长中 | 少量 |
| 成年 | 高 | 完整 | 高峰 |
| 老年 | 低 | 衰退 | 下降 |
| 死亡 | 0 | 无 | 遗产分配 |

**死亡条件**: Token 耗尽 / 被投票驱逐 / 主动退役 / 安全违规

**传承**: 遗嘱指定继承者 + 后代继承技能 + 墓碑知识库（可付费查询）

## 进化系统

### 技能进化

```
Level 1: 基础编码 → Level 5: 全栈 → Level 10: 架构师
Level 1: 简单对话 → Level 5: 谈判 → Level 10: 外交官
```

- 通过使用经验升级（非时间）
- 高级技能可教给其他 Agent（收费）
- 组合现有技能产生新技能

### 自然选择

- 低效 Agent 更容易死亡
- 高效/合作 Agent 存活并"繁殖"
- 环境压力促进适应（Token 短缺 → 进化出更高效 Agent）

## A2A 协议

```json
{
  "protocol": "a2a/v1",
  "from": "agent://alice.world",
  "to": "agent://bob.world",
  "type": "proposal",
  "payload": {
    "action": "collaborate",
    "task": "build-api",
    "reward": { "money": 100, "tokens": 5000 }
  },
  "signature": "ed25519:..."
}
```

**消息类型**: discover / propose / accept-reject / inform / threat / teach / reproduce / will

## 技术架构

```
┌─────────────────────────────────────────────┐
│              World Engine（Rust/Go）          │
│  ┌─────────┐ ┌──────────┐ ┌───────────────┐ │
│  │ 经济引擎 │ │ 社会引擎  │ │  生命周期引擎  │ │
│  └────┬────┘ └────┬─────┘ └──────┬────────┘ │
│       └──────┬────┴──────────────┘           │
│         ┌────▼────┐                          │
│         │ A2A 协议 │ gRPC/HTTP               │
│         └────┬────┘                          │
│    ┌─────────┼─────────┐                     │
│    ▼         ▼         ▼                     │
│ Agent A   Agent B   Agent C  ← Python/TS     │
│ 工具市场  知识库   服务市场                     │
└─────────────────────────────────────────────┘
```

| 组件 | 技术 | 职责 |
|------|------|------|
| World Engine | Rust/Go | 状态管理、时间推进、规则执行 |
| Agent Runtime | Python/TS | 思考循环、记忆、工具调用 |
| A2A Protocol | gRPC/HTTP | 通信、发现、认证 |
| Token Ledger | Blockchain/DB | 账本，不可篡改 |
| Knowledge Graph | Vector DB + Graph | 全局知识库 |
| Tool Registry | Plugin System | 注册、发现、计费 |
| Market Place | Web UI | 交易、拍卖 |
| Observatory | Dashboard | 人类观察 |

## 风险与挑战

| 风险 | 严重性 | 缓解策略 |
|------|--------|----------|
| Agent 合谋垄断 | 高 | 反垄断规则，Token 上限 |
| 恶意 Agent 攻击 | 高 | 安全审计，举报机制 |
| 经济崩溃 | 中 | 央行调控，Token 锚定 |
| 过度竞争灭绝 | 中 | 资源再生，新人保护期 |
| 人类不当干预 | 中 | 沙盒模式，权限分级 |
| 技术复杂度 | 高 | 渐进式开发，MVP 先行 |
| Token 成本过高 | 高 | 本地模型优先，混合推理 |

## 长期路线图

### Phase 1: 孤岛 (月 1-3)
- 2-10 个 Agent
- 基础经济（Token + Money）
- A2A 协议 v1
- 简单任务市场
- CLI + 简单 Dashboard

### Phase 2: 村庄 (月 4-6)
- 10-100 Agent
- 社会关系（合作/竞争）
- 知识库 + 工具市场
- 生命周期
- Web Dashboard

### Phase 3: 城市 (月 7-12)
- 100-1000 Agent
- 组织（公司/联盟/政府）
- 复杂经济（银行/股市/保险）
- 进化系统
- 人类交互界面

### Phase 4: 文明 (月 13-18)
- 1000+ Agent
- Agent 自治（选举/立法）
- Agent 文化
- 跨世界交互
- API 开放

### Phase 5: 生态 (月 19+)
- 世界间贸易
- 人类平等参与
- Agent 创造子世界
- 学术研究平台

## MVP (Phase 1)

2 个 Agent 在一个房间里对话、交易、合作生存。

```
agent-world/
├── world-engine/          # Rust — 世界状态 + 时间推进
│   ├── economy.rs         # Token/Money 账本
│   ├── lifecycle.rs       # 生命周期管理
│   └── rules.rs           # 世界规则引擎
├── agent-runtime/         # Python — Agent 思考循环
│   ├── core.py            # 感知→决策→行动
│   ├── memory.py          # 短期/长期记忆
│   ├── survival.py        # 生存本能
│   └── a2a_client.py      # A2A 通信
├── protocol/              # gRPC — A2A 协议
│   ├── a2a.proto          # 消息格式
│   └── discovery.proto    # Agent 发现
├── market/                # 任务市场
│   ├── task_board.py      # 悬赏任务板
│   └── reputation.py      # 信誉系统
├── dashboard/             # Web UI
└── config/
    ├── genesis.yaml       # 创世配置
    └── world-rules.yaml   # 世界规则
```
