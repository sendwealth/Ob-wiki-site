# 一堂AI数据第一课（Live251）— ADAPTED 6+1 模型

> 一堂全员必修课"AI数据必修课"系列认知篇。核心交付：ADAPTED 6+1 模型——AI数据全生命周期工作框架（预判→识别→收集→处理→使用→反馈+治理）。

---

## 核心论点

数据是AI三大驱动力（算法/算力/数据）中，普通人唯一能抓在手里的核心竞争力，也是最难速成的。一堂AI竞争力双三角中，右下角"数据"是唯一不能短期速成的要素。

---

## 三个范式巨变

| 巨变 | 从…到… | 含义 |
|------|--------|------|
| 出口变了 | "查字典"→"给教材" | 数据用途变成给AI当教材，评估标准完全变了 |
| 形式变了 | "结果表单"→"过程错题" | 过程数据（修改痕迹/踩坑记录/错误案例）比最终结果更有价值 |
| 成本变了 | "重金组队"→"AI飞轮" | AI大幅降低数据全链条门槛 |

> 用确定性的旧尺子，量不出概率性的新世界。

---

## ADAPTED 6+1 模型

```
A - Anticipate 预判：以终为始，假设驱动
D - Define 识别：界定事实、语义、优先级
A - Acquire 收集：湖仓思维，先存再处理
P - Process 处理：原始数据→理想数据（3级8种动作）
T - Transform 使用：回到场景，真正落地
E - Evaluate 反馈：评估效果，回流数据
D - Discipline 治理：合规合法，贯穿全程
```

### A 预判：三层价值假设

| 层级 | 比喻 | 时间尺度 |
|------|------|----------|
| 微观（上下文） | 教材/说明书 | 即刻可用，最高频 |
| 中观（工作流） | 燃料/助推器 | 1-3年，AI落地工作流 |
| 宏观（资产） | 护城河/核心壁垒 | 5-10年，对手无法积累 |

### D 识别：8类AI数据

事实数据、语义数据、过程数据、反馈数据、反例数据、风格数据、结构数据、多模态数据。

核心：找"暗数据"——不重视未来大概率会后悔的数据来源。

### A 收集：湖仓思维

> 很多高价值的数据，本来是金子，因为看不懂，随手就当石头扔了。

先存再处理，先保留原始再加工结构。湖可以是任何形式（Obsidian、飞书、云盘、截图收藏）。

### P 处理：3级8种

- L1 粗加工（洗菜去泥）：转写、OCR、清洗
- L2 精加工（切块装盘）：结构化、切片(RAG)、计算
- L3 注灵魂（调味熬汤）：标注、萃取

> Golden Dataset（黄金评测集）是衡量AI输出好坏最重要的数据。

### T 使用 + E 反馈

从简单到复杂：上下文投喂 → Prompt模板 → Datapack → Skill → Workflow → RAG → 微调

### D 治理

数据规范、合规边界、权限分层、生命周期管理，贯穿全流程。

## 长期心法

**相信飞轮。** 飞轮早期启动困难，一旦启动越滚越快。技能几天上手，审美几周训练，数据只能几周入门、几个月见效、几年形成核心竞争力。

> "对于一个坚定的长期主义者来说，所有短期的红利和机会都是'假'的，AI数据才是你最值得攒的'真'大牌！"
