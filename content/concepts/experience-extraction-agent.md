> 把专家隐性经验萃取成 AI 能执行的标准协议。六步萃取法（选→拆→标→铸→验→固）+ 三层标准翻译（L1 硬约束 / L2 软指标 / L3 策略层）+ 五类异常处理。可直接复制 Prompt 给 Agent 使用。

# 业务流程经验萃取（Coco Agent）

## 核心问题

专家说不清自己怎么做到的，AI 理解不了"感觉"。Coco 是中间的"翻译官"。

## 六步萃取法

1. **选**：场景界定——高频？高价值？边界清晰？最佳对象是"人觉得不难但说不清"的中间地带
2. **拆**：原子拆解——四条件（单一动作/明确输入/明确输出/可判定完成）+ 五类隐性节点（准备/检查/决策/补救/收尾）
3. **标**：标准提炼——三层标准翻译（核心步骤）
4. **铸**：协议铸造——整合为自包含执行协议 + 人机回环设计
5. **验**：验证闭环——专家审 + AI 跑 + 新手测，反例驱动迭代
6. **固**：组织固化——五角色维护 + 试点三波（灯塔→扩展→机制化）

## 三层标准翻译（核心）

| 层级 | 特点 | 示例 |
|------|------|------|
| L1 硬约束 | 布尔判断，零容错 | 禁用词=0 |
| L2 软指标 | 数值+阈值（P80/P90） | 相似度≥0.85 |
| L3 策略层 | 定性+人工闸 | 品牌调性（100%→10%抽检） |

关键翻译示例：
- "文章要专业" → "禁用词命中数=0"
- "客户意向高" → "行为评分≥80分"
- 今天的 L3 可能就是明天的 L2

## 信息收集三方法

- **COP 访谈**：Context（看到了什么）→ Operation（做了什么）→ Product（怎么判断合格）
- **现场观察**：做了什么 / 看了什么 / **没做什么**（第三种最值钱）
- **系统日志**：对比"应该"和"实际"

## 五类异常处理

输入异常 / 执行异常 / 输出异常 / 依赖异常 / 业务异常。每个异常：检测方式→处理策略→升级阈值。

## 风格指纹

把"感觉好"变成可度量：语法层（句长/段落）+ 词汇层（高频词/术语密度）+ 语义层（论证结构）+ 品牌层（黑白名单）。

## 使用方式

System Prompt + 五个功能分支提示词，复制给 Claude Code / Trae / Codex / 龙虾即可使用。
