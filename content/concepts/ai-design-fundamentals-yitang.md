# AI设计基本功 Part2 — 月白

> 讲师：月白（意大利留学7年，视觉传达+品牌传播硕士，品牌设计师）
> 来源：一堂AI俱乐部 落地Live76
> 核心理念：把脑海里模糊的审美意向变成AI能精准执行的"语言"，从"拜神"到"指挥"

---

## 一、0-1 设计怎么做（从零生图）

> [!summary] 核心：从最佳实践开始"抄"

1. **建立灵感画板**：先确定想要什么风格，再收集归类（治愈饼干、Chiikawa、泡泡玛特Molly、龙珠、迪士尼、像素小人等）
2. **"抄"的两种方法**：
   - **AI反推法**：把参考图给AI，让它帮你描述你无法表达的风格特征
   - **多图对比法**：给AI多张图，让它找出共性并描述
3. **抄完如何调**：明确画面中哪些要素是你想要的，只针对那个维度复现和调整

### 实操案例：做 emoji 风格小人

- 先选定风格方向（emoji风格）
- 用专业身份描述人物特征（五官轮廓、三庭五眼、发型等）
- 从手绘草图出发，让AI抽卡生成多个版本，选择最佳

## 二、1-10 设计怎么改（四种改图方法）

> [!summary] 月白6个月实测，覆盖90%以上专业设计改图场景

### 1. 色块法
- **逻辑**：先分区再修改。用色彩分区图把画面元素拆解，让AI明确每块区域对应什么
- **步骤**：让AI领到"地图" → 边界标注后修改变得极其简单 → 100%局部精准控制
- **场景**：修改已有图片的特定局部（更换服装、调整背景、添加元素）

### 2. 圈图指定法
- **逻辑**：直接在图片上圈出来，旁边打上小字说明，AI就知道怎么改
- **场景**：快速调整画面中某个元素的位置或属性（如"太阳移到画面正中"）

### 3. 一抽流改图法
- **逻辑**：用自然语言直接描述修改，不需要复杂描述但要精准
- **案例**：图片1中的女人的逗猫棒改成图片2中的红色蜻蜓绿色棍子的逗猫棒
- **场景**：电商场景用得特别多（产品替换、道具替换）

### 4. 替换大法

**位置替换**：保持主体不变，改变其在画面中的构图关系
- 超长提示词发现效果好但模特姿势奇怪 → 第二轮改姿势
- 场景不变但要不同视角 → 提示词或工具调整

**风格替换**：保持构图视觉风格不变，改变局部元素
- 红底大花不适合模特 → 改成白底小花

**视角替换**：保持主体不变，改变观察角度
- 方法一：提示词法 — "高级视觉重构专家"提示词，支持5种视角（正面平视/仰视/俯视/垂直俯拍/等轴测）
- 方法二：Qwen2511图片模型（liblib.art），节点自由调节镜头，推荐1024分辨率

## 三、10-1000 设计怎么定（风格锁定，批量生产）

> [!summary] 核心问题：怎么不训练模型也能锁定风格？

### 解法：逆向推理 + 风格描述三要素

**三要素**：
1. 艺术感/时代/流派特征（如莫奈印象派、Y2K酸性风）
2. 材质/光影/色彩（如哑光质感、硬朗侧光、低饱和度）
3. 情绪/氛围（如孤独清醒、温暖治愈）

### 实操步骤

1. 让AI分析参考图的风格共性 → 生成"视觉方案分析"（色彩策略、光影质感、构图视角、道具氛围）
2. 在此基础上生成**"视觉宪法白皮书"** — 一套无歧义、可复制的视觉输出标准
   - 第一条：色彩战略
   - 第二条：光影法则
   - 第三条：构图与空间
   - 第四条：材质与触感
   - 第五条：流动叙事
3. 用白皮书指导后续所有图片生成，确保风格统一

### 推荐工具

- Liblib.ai 上的 ComfyUI 工作流（溶图打光、产品精修）
- F.1 Kontext 电商万物光影融合

## 四、电商类设计 — 卖点提炼到场景落地

### 白底图 vs 场景图

| 类型 | 核心目标 | 应用场景 |
|------|---------|---------|
| 白底图 | 突出产品本体，消除干扰 | 电商主图、详情页首图、产品目录 |
| 场景图 | 构建使用场景，激发购买欲 | 详情页场景展示、社交媒体 |

### 场景图三类型
- **使用场景**：产品正在被使用
- **氛围场景**：产品所处的美好环境
- **故事场景**：产品融入微型叙事

### 设计节奏
- 视觉流：吸引 → 展示 → 说服 → 行动
- 信息分层：主图突核心卖点 → 详情页展开功能/细节/场景/信任证明/行动号召

### 卖点提炼
- 把产品优势翻译成AI能理解的视觉语言
- 把感觉变成具体、AI能明白的自然语言

## 五、线下实体门店 — 不同行业不同打法

> [!note] 核心差异：线上设计在手机之内，线下设计在手机之外

### 各行业设计要点

**餐饮**：高饱和度色彩、特写镜头、蒸汽热感元素 → 菜单/门口海报/桌贴/外卖包装

**零售/快消**：突出卖点、时尚感、引导动线 → 橱窗海报/店内吊旗/货架贴/促销挂牌
- AI做橱窗方案：3分钟跑出10套方向（以前是找参考→画草图→改方案→做效果图→反复沟通）

**服务业/体验**：传递专业信任舒适活力 → 服务介绍板/价目表/环境展示图/会员海报

### 打印材质与AI出图配合

| 要素 | 要求 |
|------|------|
| 分辨率 | 易拉宝150DPI，大型喷绘300DPI |
| 色彩模式 | 屏幕RGB → 印刷CMYK，提前转换 |
| 出血线 | 预留3mm |
| 材质特性 | 背胶影响色彩、灯箱需更明亮通透、易拉宝避免边缘重要信息 |

## 六、口喷作图心法（核心中的核心）

> [!important] 先喷到"喷无可喷"，再打开任何设计软件

### 流程

1. **先喷**：彻底的口头描述所有画面要素
2. **AI生成**：基于描述初次生成
3. **AI调图**：在生成结果上迭代优化
4. **人工精修**：确认所有细节后才启动PS

### 图片维度的本质变量

- **主体**：是什么人/物？穿着什么？什么姿势？
- **场景**：室内还是户外？具体环境细节？
- **风格**：插画/摄影/3D渲染？参考哪位艺术家？
- **构图**：全景/中景/特写？什么视角？
- **光影**：自然光还是人造光？什么角度？什么质感？
- **色彩**：什么色调？饱和度？对比度？
- **情绪与氛围**：欢快/静谧/神秘/孤独？

### 关键认知

> 你脑海里的审美决定了图片的上限，AI只是执行力超强的"施工队"。你的审美和判断力是指挥官，AI是听令行事的士兵。

## 七、AI设计三段位

| 段位 | 阶段 | 目标 |
|------|------|------|
| L1 | 对话生图 | 通过提示词反复调整，目标"可用"不是"完美" |
| L2 | AI调图 | 图生图、局部重绘、智能扩图，调到AI无能为力 |
| L3 | 人工精修 | PS等软件精雕细琢，解决AI无法处理的精细部分 |

> 配套认知：需要"烧"够足够多的Token才能亲身体验和判断哪个模型、哪套工作流最适合自己。月白6个月纯Token消耗近2万人民币。

## 八、生图模型推荐（文科生/人文设计方向）

| 用途 | 首选 | 理由 |
|------|------|------|
| 文字对话与提示词优化 | Claude Code | 逻辑推理能力更强 |
| 日常直接生图 | 豆包 | 智价比最高 |
| 人文艺术类图片生成 | Gemini | 谷歌艺术部门语料库，人文气息和叙事感更强 |

### Gemini vs GPT 的关键差异

- Gemini 人文艺术感知更强，画面更有"味道"
- 国内AI生成"富人"= 上海摩天大楼+西装精英（制式化）
- 外国AI生成"富人"= 私人飞机+爱马仕（叙事感）
- 在需要文化深度和独特审美的项目中，这个区别是决定性的

## 九、完整提示词模板摘录

### 美食摄影提示词（案例：西安三件套）

```
真实美食摄影，西安老街边小店场景，自然光柔和侧逆光，光影自然不生硬。
前景是一份地道西安三件套：一碗红油凉皮（酱汁油润不反光，红油通透有光泽...）、
一个刚出炉的肉夹馍（饼皮金黄有自然烤痕，肉馅肥瘦相间...）、
一瓶有实质感的冰峰汽水（玻璃瓶通透，液体质感自然...）。
整体画面色彩柔和自然，没有过度饱和...8K高清，商业美食摄影，真实食物质感。
```

### 拼贴风格海报提示词（案例：长沙旅游）

```
Role: 精通拼贴艺术与潮流视觉传达的新锐平面设计师
Style: 剪影拼贴、高饱和度、街头潮流、趣味搞怪
Elements: 夸张块状字体 + 趣味Emoji贴纸 + 手绘装饰箭头 + 气泡框
Composition: 前景人物动态抓拍 + 背景地标街景 + 信息层级清晰
Input Variables: 主色调/主标题/副标题/气泡口号/卖点标签/背景场景/人物互动/漂浮道具
```
